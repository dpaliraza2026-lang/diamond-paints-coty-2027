# Diamond Paints — Colour of the Year 2027 Ebook (Landscape Monograph)
## Shade: Yellow Aster | DCM Code: QC0083 | RGB: 254, 236, 123 (#FEEC7B)

This draft publication has been prepared strictly according to the editorial and architectural specifications provided by the Head of Department (HOD) for Diamond Paints.

### Format & Design Doctrine
- **Layout:** Widescreen Landscape (A4 Landscape / 16:10 presentation spread, 1360px width) for maximum architectural visual impact.
- **Typography:** `Manrope` (body, metadata, technical tables) + `Didot` / `Bodoni Moda` (editorial headings).
- **Clean Geometry:** Strictly `2px` border radius throughout.
- **Zero Drop Shadows:** `box-shadow: none !important;` (no glow, no shadows).
- **Zero Hover Animations:** Static, clean editorial document ready for screen presentation and PDF export.
